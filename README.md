# 👻 Haunted Terminal & Ghost Shell Whisperer

> Built for **Hacktoberfest 2026 Week 4: Ghost in the Machine**

A spooky, local-first terminal companion that watches your shell commands and whispers eerie, contextual commentary using lightweight open-source AI logic—all without internet or closed APIs.

## Why Open Innovation Matters Here
- **Zero Internet Required:** Works completely offline on your local machine with the lights (and Wi-Fi) turned off.
- **Privacy First:** Your terminal commands and file paths never leave your local workspace to feed a third-party server.
- **Customizable Spirits:** Easily swap response rules or plug in local Ollama models.
